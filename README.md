# 2026年度　画像・映像コンテンツ演習4 最後の林檎によるプロジェクト「ケーキを作ろ」

(注)本リポジトリは著作権を含むアセット等のファイルを削除しております。

『ケーキを作ろ』はケーキへの自由な飾り付けを楽しむ「音声認識×シューティング」ゲームです。

1000種以上のトッピングを声で呼び出す機能と、Joy-Conによる配置で没入感ある創作体験を提供します。

## 制作意図・コンセプト

コンセプトは「ケーキ作りを通した創作体験の提供」です。音声認識とシューティングを掛け合わせたゲームです。

本作品は、「立体視用インタラクティブコンテンツ」をテーマに開発が始まりました。インタラクティブ性を生み出す技術として、着目したのが3Dモデル呼び出しの技術です。プレイヤーが自由に3Dモデルを呼び出し、ゲーム内に反映させる仕組みは「発想する楽しさ」を提供できると考察しました。そして、この楽しさを最大化する題材として、「ケーキの飾りつけ体験」を選択しました。

一連の創作体験の質を向上させる仕様として、声で直感的にトッピングを呼び出す「音声認識」と、手先で狙いを定めてトッピングを射出する「Joy-Con操作」というマルチモーダルUIを採用しています。さらに、飾り付けに対してフィードバックを与え、達成感を誘発するために、飾り付けの「上手さ」を定量評価する採点・ランキング機能を導入しました。

## 制作プロセス

開発期間は約2か月です。初めの2週間でコンセプトを磨き込んだのち、メンバーで分担して開発しました。

まず、トッピング選択の高い自由度を実現するために、Stable DiffusionとStable Fast 3Dによる3Dモデル自動生成パイプラインを構築し、1000種以上のトッピングモデルを効率的に準備しました。また、音声認識によるトッピング呼び出しには、ローカルサーバーにてNMeCabとFastTextを活用し、単語同士のコサイン類似度を比較することで、高速かつ外部通信に依存しない安定した処理を実現しました。

さらに、立体視の没入感を極めるべくSide-by-Sideと2D Depthを比較検証し、最終的に深度表現の強い2D Depthを採用しました。加えて、デフォルトではUIが深度バッファへ書き込まれず立体化しない問題に対し、自作のカスタムUIシェーダーを開発して解決しました。
